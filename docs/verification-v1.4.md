# v1.4 验证记录

验证日期：2026-09-21。

## 自动化回归

运行 `node tests/generator.test.cjs`，退出码为 0。

- 17 个总类别、138 个下级选项、8 种风格。
- 基础回归验证 22,264 批、222,466 个名称，检查默认 2–6 字、批内去重和关键词位置。无关键词的默认范围要求十个结果；加上关键词且可用组合不足时，检查实际数量和提示。
- 追加 1,104 组范围测试，实际得到 9,098 个符合条件的名称，检查 3–5 字与固定 4 字、完整关键词和位置；条件不足时允许少于十个。
- 追加 119 组全类别固定长度测试，逐一检查 2 至 8 字，实际得到 791 个名称；确认普通姓名不会补长至 5–8 字，功法／阵法／秘术在较长范围仍有候选。
- 验证固定三字人名、扩展汉字计数、空输入回到默认范围、2–8 边界、非整数、上下限冲突、关键词过长、关键词中间位置所需空间、无结果时禁用复制。
- 验证三字、七字和八字剑法保留完整类别后缀，同批不只更换“剑诀／剑经／剑法”来重复同一个主体。
- 检查自动重复字、重复词与冰火冲突过滤；保留用户主动指定的冰火组合。回归“烈火焰炎诀”等同义意象堆叠问题。
- 验证常见关键词意象辅助、明确下级类别优先、多意象不猜测，以及关键词在组合中重复堆叠的过滤。
- 验证原位锁定、单条替换、全部锁定、更改设置后解除锁定，以及跨批去重。
- 验证人物风格用字、扩展汉字关键词及姓氏不被截断。
- 验证旧版收藏读取、JSON 结构校验、合并去重、同名备注保留、编辑重名拒绝、导出导入往返、撤销与容量限制。
- 验证保存失败时保留内存数据并显示提示；损坏的原存储不被自动覆盖。
- 验证复制兼容路径返回失败时，不显示成功提示。

这些断言验证规则和交互状态，不代表对每个名称的文学质量或唯一性作出保证。

## 浏览器检查

在本机 HTTP 预览中实际操作：

- 锁定一个候选后换批，原候选仍在原位置。
- 收藏、改名和写备注，清空后撤销，刷新后仍能恢复收藏。
- 导入含同名条目的 JSON，已有备注保留，新条目加入。
- 导出 JSON 文件已下载到磁盘，并核对两条测试数据和备注完整。浏览器工具的下载事件监听超时，但实际文件生成成功。
- 检查桌面布局以及 390 × 844 窄屏布局、收藏编辑弹窗。修正窄屏复制按钮换行。
- 浏览器检查时未观察到错误或警告日志。
- 实际检查带“烈火”关键词的 3–5 字结果、固定三字人名、上下限冲突提示，以及不可达长度时的空结果与复制按钮禁用状态。
- 本轮进一步检查：初始范围显示 2–6；固定两字法宝生成完整短名；7–8 字剑法产生如“四象分光化影剑诀”“青云山回风剑经”的完整词组；“烈火”前置的结果遵守范围，并使用“燎原”“炼气”等搭配；无关键词的固定八字普通姓名显示零结果并禁用复制。

## 验证限制

浏览器工具的安全策略禁止直接导航到本地 `file://` 页面，因此未完成直接双击 HTML 的端到端检查。程序仍是无外部脚本、无外部样式依赖的单文件；本机 HTTP 预览不等于所有浏览器的文件模式兼容性验证。

本次未进行 Safari、Firefox、实体手机或辅助技术的全面测试。收藏依赖浏览器本地存储，重要内容应导出备份。
