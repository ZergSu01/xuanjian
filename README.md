# 玄鉴 · 玄幻名词生成器

玄鉴是一款面向中文玄幻创作的离线命名工具，帮助你为人物、功法、法宝、宗门与山川秘境寻找命名灵感。选择类别与风格，也可以加入自己的关键词，生成一组候选名称，再将喜欢的结果复制或收藏。

整个工具封装在一个 HTML 文件中，用浏览器打开即可使用，无需安装依赖或配置 API，输入与收藏均保留在本地。

本项目由作者使用 **OpenAI Codex** 辅助制作；名称生成采用本地词库与随机组合规则，运行时无需调用 AI 服务。

当前程序版本：**v1.4**。

## 开始使用

下载并解压本项目，在文件夹中双击 `index.html`，用浏览器打开即可。Mac 用户也可以右键文件，选择“打开方式”，再选择浏览器。

无需安装软件包、启动服务器、配置 API 或联网。HTML 中已经包含界面、样式、词库和生成逻辑。查看来源链接时需要联网。

## 功能

- 17 个总类别、138 个下级选项（包含各类的“不限”或随机选项）。
- 8 种风格：混合、古朴、仙侠、江湖、道门、佛门、魔道、妖异。
- 关键词可留空，可选择自动融合、开头、中间或末尾。
- 每批目标为 10 个不重复候选；优先避开当前设置下最近 100 个候选，组合不足时会提示放宽跨批去重。
- 锁定候选并保留原位置，其余换一批；也可以单独替换一条。更改设置会解除锁定。
- 人物姓名支持性别、姓名结构、指定姓氏与风格用字。
- 功法、丹药、材料、阵法、秘术和部分典籍采用下级分类搭配词；词素连接处消除重复片段。
- 收藏夹最多保存 500 个名称，支持改名、自定义备注、搜索、逐条删除和撤销上次修改。备注可记录招式背景、使用人物、级别等信息。
- 支持 JSON 备份导入导出和 TXT 文本导出。导入采用合并模式，同名保留已有备注，超过容量时整批拒绝。

| 大组 | 总类别 |
| --- | --- |
| 人物与名号 | 人物姓名、道号 / 法号 |
| 修炼与术法 | 功法招式、秘籍典籍、秘术神通、阵法禁制、体质血脉 |
| 器物与资源 | 法宝兵器、丹药灵液、材料矿物 |
| 生灵与势力 | 生灵异兽、门派宗门、机构组织、国家部族 |
| 地理与空间 | 据点地名、地域大陆、秘境洞天 |

## 使用方法

1. 选择总类别及下级选项。
2. 按需输入关键词，选择位置和风格；人物类别可设置性别及姓氏。
3. 点击“生成十个”，或按回车。
4. 点击“锁定”保留喜欢的候选，再换一批；点击“换一个”只替换该条。
5. 点击“收藏”放入收藏夹，按需改名、添加备注或搜索；点击“复制”或“复制全部”取用名称。
6. 定期用“导出备份”保存 JSON；换浏览器时用“导入备份”恢复。TXT 文件用于阅读与分享，不用于恢复。

关键词位置以完整生成结果为准：“开头”以关键词起首，“末尾”以关键词结尾，“中间”在关键词前后保留文字。“自动融合”随机选择位置。

## 使用边界

- 本工具使用本地词库与随机组合规则，不是 AI 服务，不判断名称是否已被其他作品使用，也不保证每个组合都符合语义。
- 关键词输入会去掉空白、标点和符号，并按 Unicode 码点保留前 6 个字符；推荐使用 1–6 个汉字。指定姓氏最多保留 4 个字符。
- 人物设置关键词后，关键词位置优先于固定姓名字数；选择“开头”时，关键词会替代姓名起首部分，此时指定姓氏不会保留。
- 人物性别影响用字池，不表示每个结果都有明确性别。道号 / 法号的性别选项主要影响“不限”下级选项的称谓池。
- 指定关键词在末尾时，类别后缀可能被替换，因此结果不一定仍以“剑”“宗”等字结尾。
- 每个空位最多尝试 500 次；极端组合下可能不足 10 个，界面显示实际数量。自动检查主要针对重复字与关键词位置，不保证语义自然。
- 收藏保存在当前浏览器的本地存储中，不上传，也不同步。隐私模式、浏览器限制、清理数据或移动 HTML 文件可能影响收藏；重要结果请导出 JSON 备份。保存失败时会显示提示，不会把未落盘的收藏表示为已持久保存。
- 浏览器可能限制本地文件的剪贴板访问。如复制未生效，请手动选中文字复制。

## 从 v1.3 升级

v1.4 可以读取旧版的字符串数组收藏，并使用新的独立存储键保存收藏夹，不覆盖旧版收藏。只有新页面能访问原浏览器同一存储区域时，才会自动读取；移动或重命名本地 HTML 文件可能改变存储区域。建议先保留旧文件与收藏内容，再升级。

撤销仅针对当前页面上最后一次收藏夹修改，刷新后不保留。读取到损坏的本地数据时，不会自动覆盖原数据；本次收藏可以继续在页面内使用并导出备份。

## 开发与检查

程序无需构建。修改 `index.html` 后刷新浏览器即可。

维护者可安装 Node.js 后执行：

```sh
node tests/generator.test.cjs
```

测试使用固定随机种子，在最小 DOM 模拟环境执行页面原脚本，覆盖所有总类、下级选项和风格，检查每批数量、去重、关键词位置、人物风格、分类切换，以及锁定、单条替换、旧收藏迁移、导入导出、编辑、撤销、容量限制、存储失败和复制失败。不替代真实浏览器的界面、剪贴板和持久存储兼容性测试。
